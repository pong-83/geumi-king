# 금이로그

피그미다람쥐 개인용 케어 기록 앱이에요. 휴대폰 홈 화면에 추가해서 앱처럼 쓰는 PWA이고, 기록은 노션 데이터베이스에 쌓여요.

- **오늘**: 생후 주차, 주차별 식단 가이드, 챙길 것(물 교체 D+n, 사료 전체 교체, 이번 주 과일·웜·영양제, 사진 인증, 분양보증 캡처, 적응기간)
- **기록**: 식단(밀프로 · 후르츄 · 웜 · 익스 넣어준 양/교체 · 과일 큐브 · 영양제 · 물 교체 · 꿀/젤리 · 사료 전체 교체), 몸무게 + 저울 사진, 컨디션, 온도·습도 경고, 청소, 핸들링, 사진·영상, 메모. 입력하면 자동 저장돼요.
- **앨범**: 날짜별 사진·영상
- **월간**: 달력, 통계, 몸무게·사료·온도 그래프, 회고 메모, 인쇄·PDF 저장, CSV 다운로드
- **케어시트**: 드길샵 케어시트 검색 (앱 키로 잠금)

## 어떻게 저장되나요

```
휴대폰 (앱, 로컬 저장) ──▶ Cloudflare Worker (노션 토큰 보관) ──▶ 노션 데이터베이스
```

- 기록은 먼저 휴대폰에 저장되고, 연결돼 있으면 노션으로 옮겨져요. 인터넷이 없어도 기록할 수 있어요.
- GitHub Pages는 누구나 코드를 볼 수 있어서 노션 토큰을 앱에 넣으면 노출돼요. 그래서 토큰은 워커에만 두고, 앱은 **앱 키**로 워커에 접근해요.
- 사진은 1600px JPEG로 줄여서 노션에 올려요. 노션 무료 플랜은 **파일당 5MB**라서 영상은 5MB 이하만 올라가요 (설정에서 바꿀 수 있어요). 워커 무료 플랜은 하루 10만 요청이라 개인용으로 충분해요.
- **케어시트는 외부 공유 금지 자료라서** 저장소에는 암호문(`data/caresheet.enc.json`)만 올라가요. 앱에서 앱 키를 넣어야 열려요.

## 설치 (한 번만)

### 1. 노션 준비
1. https://www.notion.so/profile/integrations 에서 **새 통합(내부)** 을 만들고 시크릿(`ntn_...`)을 복사해요.
2. 노션에 빈 페이지를 만들고 `/database` → **데이터베이스 - 전체 페이지**로 "피그미 기록" 데이터베이스를 만들어요. 속성은 앱이 알아서 만들어요.
3. 데이터베이스 오른쪽 위 `•••` → **연결** → 1번에서 만든 통합을 추가해요.
4. 데이터베이스 주소 `notion.so/xxxx/`**`32자리ID`**`?v=...` 에서 32자리 ID를 복사해요.

### 2. Cloudflare Worker 배포
1. https://dash.cloudflare.com 에 가입하고 **Workers & Pages → 만들기 → Worker** 로 `pygmy-care-notion` 을 만들어요.
2. 코드 편집에서 `worker/src/index.js` 내용을 그대로 붙여넣고 배포해요.
3. **설정 → 변수 및 비밀**에 아래 네 개를 넣어요.
   | 이름 | 종류 | 값 |
   |---|---|---|
   | `NOTION_TOKEN` | 비밀 | 노션 통합 시크릿 |
   | `NOTION_DB_ID` | 비밀 | 데이터베이스 ID |
   | `APP_KEY` | 비밀 | 앱 키 (따로 전달받은 값) |
   | `ALLOWED_ORIGIN` | 텍스트 | `https://pong-83.github.io` |
4. 워커 주소(`https://pygmy-care-notion.<계정>.workers.dev`)를 복사해요.

> 터미널을 쓴다면 `cd worker && npx wrangler deploy` 후 `npx wrangler secret put NOTION_TOKEN` 처럼 넣어도 돼요.

### 3. GitHub Pages
저장소 **Settings → Pages → Branch: main / root** 로 켜면 `https://pong-83.github.io/geumi-king/` 에서 열려요.

### 4. 앱 연결
1. 휴대폰 사파리에서 앱 주소를 열고 **공유 → 홈 화면에 추가**.
2. 아이 정보를 넣고, 오른쪽 위 ⚙️ 설정에서 **워커 주소**와 **앱 키**를 넣은 뒤 **저장 · 연결 확인**을 눌러요. 노션 데이터베이스에 속성이 자동으로 생겨요.

## 노션에서 보기 팁
- **표 보기**: 날짜 내림차순 정렬, `종류 = 일지` 필터
- **캘린더 보기**: 날짜 기준으로 한 달 기록을 한눈에
- **갤러리 보기**: 카드 미리보기를 "페이지 콘텐츠"로 두면 사진이 보여요
- 월간 회고는 `종류 = 회고` 로 따로 쌓여요.

## 케어시트를 고칠 때
원문 JSON은 저장소 밖에 보관해요. 고친 뒤 다시 암호화해서 올려요.
```
node tools/caresheet.mjs encrypt caresheet.json <앱 키> > data/caresheet.enc.json
```
앱 키를 바꾸면 케어시트도 새 키로 다시 암호화하고, 워커의 `APP_KEY`도 같이 바꿔요.
